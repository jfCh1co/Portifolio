# 🚀 Portfólio — José Francisco

Portfólio pessoal desenvolvido para apresentar meus projetos, habilidades e experiências na área de tecnologia.

O projeto foi desenvolvido utilizando **HTML, CSS, JavaScript e GSAP**, com foco em uma interface moderna, responsiva e interativa.

## 🛠️ Tecnologias utilizadas

- **HTML5** — Estrutura e semântica da aplicação
- **CSS3** — Estilização, responsividade e efeitos visuais
- **JavaScript** — Interações e funcionalidades
- **GSAP** — Animações e transições
- **ScrollTrigger** — Animações baseadas no scroll
- **ScrollToPlugin** — Navegação suave entre seções

## ✨ Funcionalidades

- 🎨 Design moderno e minimalista
- 📱 Layout totalmente responsivo
- ⚡ Animações utilizando GSAP
- 🖱️ Microinterações nos elementos
- 📜 Navegação suave entre seções
- 📌 Navegação ativa conforme a seção atual
- 📱 Menu mobile
- ⬆️ Botão para voltar ao topo
- 🧑‍💻 Seção sobre mim
- 🚀 Seção de projetos
- 🛠️ Seção de tecnologias e habilidades
- 📬 Área de contato
- 🔗 Links para redes sociais e projetos
- ♿ Suporte para `prefers-reduced-motion`

## 🎬 Animações

O portfólio utiliza a biblioteca **GSAP (GreenSock Animation Platform)** para criar uma experiência mais dinâmica.

Foram utilizadas animações para:

- Entrada dos elementos do Hero
- Animações durante o scroll
- Animação dos títulos das seções
- Entrada dos cards de projetos
- Animação das habilidades
- Efeitos de hover nos projetos
- Animação dos links de contato
- Parallax no Hero
- Navegação suave
- Animação do botão "Voltar ao topo"
